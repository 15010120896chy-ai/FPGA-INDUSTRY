# 缺陷智能分析平台（DeepSeek 版）使用说明比一年前"LM Studio 本地模型 + 单页 HTML 直连 1234 端口"的方案，这是一个完整的升级版：| 对比项 | 一年前的方案 | 现在的方案 ||---|---|---|| 模型能力 | 本地 LM Studio，受电脑显卡限制，一般只能跑 7B 左右的小模型 | DeepSeek 云端 V3 系列大模型（671B 级 MoE），能力接近 GPT-4o 级别 || 调用方式 | 浏览器直接 fetch 本地 127.0.0.1:1234 | 本地小代理服务转发（server.py），天然规避跨域(CORS)限制 || API Key 安全 | 无需 Key | Key 只保存在本机浏览器 localStorage，不经任何第三方页面 || 输出体验 | 一次性整段输出 | 流式输出（打字机效果） || 交互方式 | 点一次按钮，只能得到一次结论 | 多轮对话：生成报告后可继续追问，AI 记住数据上下文 || 推理过程 | 无 | 可选 deepseek-reasoner 模型，展示"思考过程"，答辩很加分 || 数据灵活性 | 数据写死在代码里 | 页面上直接编辑/增删缺陷数据，图表实时刷新，AI 用最新数据分析 || 部署 | 要手动改网络适配器 IP 才能给树莓派访问 | 双击 start.bat 即用；以后要局域网访问只需改一行配置 |---## 一、五分钟上手### 第 1 步：注册 DeepSeek 开放平台，拿 API Key1. 打开 https://platform.deepseek.com （需用手机号注册）2. 左侧菜单 ->「API Keys」-> 创建 API Key（形如 sk-xxxxxxxx），创建后只显示一次，立刻复制保存3. 左侧菜单 ->「充值」-> 充 10 元就够用很久（一次分析约几百 token，折算约几分钱）### 第 2 步：启动网站双击 ai-web 文件夹里的 start.bat，会自动打开浏览器访问 http://127.0.0.1:8765 。（首次使用要求电脑联网；那个黑色窗口不要关，关掉就是停止服务。）### 第 3 步：配置 Key1. 点网页右上角 设置2. 粘贴 API Key3. 点 测试连接，显示"连接成功"即可4. 点 保存（Key 会记住，下次不用再填）### 第 4 步：使用1. 左侧表格可直接修改数据（改数量、改名、增删行），图表和统计实时更新2. 点 生成 AI 分析报告 —— 等 1~3 秒，结论会流式"打"出来3. 之后在下方输入框继续追问，例如：   - "褶皱占比最高，可能是什么工艺问题？"   - "按改进成本从低到高排个序"   - "给一段能写进论文的结论摘要"---## 二、设置项说明| 设置 | 说明 ||---|---|| API Key | DeepSeek 密钥，只存在本机浏览器里，不会发到任何第三方 || 接口地址 | 默认 https://api.deepseek.com ，一般不用改 || 模型 | deepseek-chat（通用对话、性价比高，推荐日常用）；deepseek-reasoner（带思考过程，适合答辩演示） || 温度 | 0 = 最稳定保守；1 = 更有创造性。分析报告建议 0~0.5 |---## 三、常见问题**Q1：为什么不能像以前那样直接双击 HTML 用？**DeepSeek 云端 API 有跨域(CORS)限制，浏览器直接调用会被拒绝（"跨域请求被拒绝"就是这个原因）。所以需要一个本地小服务 server.py 做转发 —— 这也是目前所有浏览器 AI 应用的推荐架构（BFF）。它只在本机 127.0.0.1:8765 运行，不占用公网，安全无副作用。**Q2：一次分析花多少钱？**一次完整报告约 300~800 token（输入约 600 token + 输出约 300 token），以官方价格（输入缓存未命中约 $0.28/百万、命中 $0.028/百万，输出约 $0.42/百万，2025-09 起统一价，具体以官方价格页 https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 为准）计算，单次约人民币几分钱。充 10 元能做几百次分析。**Q3：比赛现场没网怎么办？**云端 API 需要联网。两个办法：- 现场一般有 WiFi/手机热点，够用；- 想完全离线：在"接口地址"填 http://127.0.0.1:1234/v1 ，然后照旧启动 LM Studio 的本地 Server，  页面就能无缝切回本地模型（模型名填你加载的模型名）。多轮对话、流式输出照常工作。**Q4：Key 会不会泄露？**页面 -> 本机代理 -> DeepSeek，全程只有你自己的电脑参与；Key 存在浏览器 localStorage，不写进代码、不发往任何第三方域名。**Q5：怎么让树莓派 / 评委电脑通过局域网访问？**把 server.py 顶部的 HOST = "127.0.0.1" 改成 HOST = "0.0.0.0"，重启服务，然后在 Windows 防火墙放行 8765 端口。其他设备用 http://你的电脑IP:8765 访问。（和一年前相比，不用再手动改网络适配器 IP 了。）---## 四、文件结构```ai-web/├─ start.bat      # 双击启动├─ server.py      # 本地代理服务（转发 DeepSeek，零依赖）├─ index.html     # 网站页面（图表 + 多轮对话）└─ 使用说明.md     # 本说明```技术栈：纯 HTML/CSS/JS（Chart.js 画图）+ Python 标准库代理，没有任何需要安装的依赖。
